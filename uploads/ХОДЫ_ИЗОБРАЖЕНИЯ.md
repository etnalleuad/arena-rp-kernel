# ХОДЫ ИЗОБРАЖЕНИЯ

Реестр User-ходов, пришедших картинками/скриншотами, и текстовых следов, по которым их можно восстановить. Старые анализы, сырьё и канон не изменялись.

## Правило источника

Если в сырье есть только ответ Model «прочитал со скриншота», это **не дословная цитата User**. Содержимое изображения не восстанавливается догадкой; ниже отмечено, какой физический скриншот нужен для полного аудита. Приведённые цитаты — только реально сохранившиеся в `.txt` строки Model/OOC или встроенное текстовое описание изображения.

### Потерянные вложения, которые нельзя подменять текстом

1. Исходные скриншоты User-ходов Chat1–5 — не часть текущего workspace и не извлечены из `.txt`.
2. Рендеры и фотографии квартиры в Chat5: в тексте сохранены OOC-описания и ссылки на `plan.svg`, но не доказано, что исходные пользовательские картинки доступны как отдельные файлы в этой задаче.
3. Татуировка/внешний вид и фото интерьера, упомянутые User-строками Chat5 137 и 7292, требуют самих вложений для image-level проверки.
4. Музыкальные скриншоты/материал Ксаны и точный канал песен в Chat5 — только косвенно доступны через пересказы; не выдавать их за дословно прочитанные изображения.

## Что считать доказанным

- Доказан факт наличия image-хода, если следующий Model-OOC прямо говорит «скриншот», «с картинки» или «текст со скрина».
- Доказан только контекст, который Model назвал в этом OOC; весь остальной User-текст остаётся **неизвлечённым**.
- Ни одна потерянная картинка не превращается в выдуманную цитату, а новый отчёт должен считать такие места «непрямой доступностью», а не полным покрытием.
