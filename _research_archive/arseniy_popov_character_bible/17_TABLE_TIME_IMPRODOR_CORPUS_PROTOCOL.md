# 2. Почему это не просто «игровое шоу»

В каждом сезоне участники по очереди:

- объясняют собственную игру;
- становятся игроками в чужом правиле;
- спорят о справедливости;
- проигрывают;
- выигрывают;
- помогают;
- мешают;
- образуют ситуативные коалиции;
- устают;
- вспоминают прошлое;
- реагируют на предметы, еду и пространство.

Это позволяет сравнить Арсения **с самим собой в разных статусах**.

# 3. Ролевое разделение

## ROLE-A — AUTHOR/HOST

Арсений объясняет свою игру.

Кодируем:

- приветствие;
- структуру правил;
- примеры;
- реакцию на перебивание;
- повтор правила;
- наказание;
- уступку;
- изменение правила по ходу;
- терпение;
- контроль времени;
- финализацию.

## ROLE-B — PLAYER

Арсений играет по чужому правилу.

Кодируем:

- вопросы;
- сопротивление;
- принятие;
- спор;
- поиск лазейки;
- проигрыш;
- победу;
- обвинение ведущего;
- поддержку другого игрока.

## ROLE-C — OBSERVER/COMMENTATOR

Игра временно не требует действия Арсения.

Кодируем:

- комментирует ли чужой ход;
- помогает или мешает;
- поддерживает ли шутку;
- остаётся ли вне разговора;
- кого выбирает адресатом.

## ROLE-D — CHARACTER

В «Импродоре» и отдельных играх участник может говорить от роли.

Такой текст получает `CHARACTER_SPEECH` и не смешивается с бытовым голосом.

# 6. Address Layer

Для каждого прямого обращения:

```text
VOCATIVE:
TARGET:
POSITION: start / middle / end
FUNCTION: attention / command / plea / accusation / joke / support
VOLUME:
REPEATED:
TARGET_RESPONSE:
```

Особенно разделяем:

- `Серёж, ...` — прямое обращение;
- `с Серёжей` — упоминание;
- `он сказал: «Серёж…»` — цитирование;
- `пацаны` — коллектив;
- `козлы вонючие` — коллективный игровой подкол-кандидат.

---

# 7. Profanity Layer

Каждая грубая реплика получает:

```text
PF_LEVEL: L0–L4
PF_FUNCTION:
TARGET: self / person / group / object / rule / situation
PLAY_FRAME: clear / ambiguous / absent
LAUGHTER_AFTER:
REPAIR_AFTER:
```

## Особый тест

Если фраза звучит резко, но после неё немедленно идёт счёт, правило или следующий ход, это аргумент в пользу игровой функции, но не окончательное доказательство.

---

# 8. Fatigue Curve

Каждый полный сезон делится на квартали:

- Q1 — первые 25%;
- Q2;
- Q3;
- Q4 — последние 25%.

Сравниваем:

- длину реплики;
- частоту перебиваний;
- мат;
- подколы;
- уход от правил;
- физическую позу;
- скорость возврата к задаче;
- ошибки;
- готовность объяснять.

Это позволит отделить стабильную черту от поведения после нескольких часов съёмки.

---

# 9. Баланс выборки

Нельзя анализировать только самые вирусные сцены.

Для каждого сезона берём:

1. все игры Арсения как автора;
2. минимум две игры других участников;
3. первый конфликт правил;
4. первый проигрыш Арсения;
5. первую победу;
6. одну нейтральную длинную фазу;
7. финальное подведение результатов;
8. Q1 и Q4 для усталости.

После пилота — полный сезон.

# 10. Первый проход по сезонам 1–5

## Pass A — структура

- разбить полносезонное видео на 8 эпизодов;
- установить оригинальную дату эпизода;
- определить автора каждой игры;
- сохранить начало и конец.

## Pass B — спикер

- выделить все реплики Арсения;
- определить наложение голосов;
- маркировать неразборчивое;
- проверить обращения и мат.

## Pass C — события

- ошибка;
- спор;
- подкол;
- помощь;
- проигрыш;
- победа;
- восстановление.

## Pass D — паттерны

Сравнить роли AUTHOR и PLAYER.

# 11. Отдельный протокол «Импродора»

«Импродор» нельзя анализировать как обычный «Тейбл Тайм» без дополнительных меток.

Нужно разделить:

- участника Арсения;
- игрового персонажа;
- решение игрока;
- решение персонажа;
- реакцию на кубик;
- реакцию на сюжетный риск;
- переговоры с командой;
- мета-комментарий о правилах.

## Главные вопросы

- кто предлагает план;
- кто принимает риск;
- как Арсений спорит с мастером;
- как реагирует на случайность;
- поддерживает ли чужую роль;
- выходит ли из персонажа ради правила;
- как распределяет ответственность за решение.

# 13. Критерий завершения

Пилот считается завершённым, когда:

- размечен минимум один полный сезон;
- получено не менее 200 speaker-confirmed реплик Арсения;
- есть минимум 30 прямых обращений;
- есть минимум 15 спорных/конфликтных событий;
- есть минимум 10 проигрышей и 10 побед/удачных ходов;
- есть 10 эпизодов помощи или защиты;
- мат разделён по функциям;
- сформированы контрпримеры;
- ни одна персонажная реплика не попала в бытовой словарь.
