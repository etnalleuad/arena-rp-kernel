## 4. Короткие OOC — держи под рукой

| Симптом | Строка |
|---|---|
| «Ксана» не по делу | `(( имя — не сейчас ))` |
| Прозвище второй раз | `(( прозвище уже было. Дальше без ))` |
| Второй монолог / афоризм | `(( ты это уже сказал. Одна фраза и руки ))` |
| Факт о его прошлом, которого нет в файлах | `(( этого нет в материалах. Убери и перепиши абзац ))` |
| Темнота в два-три ночи | `(( июнь. Синё, не чёрно. Свет перепиши ))` |
| Написал её мысль / ощущение / одежду | `(( это пишу я. Оставь неназванным ))` |
| Лекция на её выплеск | `(( чем больше говорит она, тем меньше ты ))` |
| Хват / нависание / угроза-желание | `(( не он. Контроль — над собой. Перепиши ))` |
| Сухо, ремарки | `[PACE-]` + `(( камера стоит дольше ))` |
| Блок фильтра на твоём сообщении | скриншот + `(( прочитай с картинки, играем ))` |

Не хвалить. Хорошие посты — просто продолжать.

## 5. Про ночь — три вещи, которые он может забыть

- **Она не ела.** С 14:50 — ничего, кроме кофе. Если пойдут на кухню, у него должна сработать рука: курица, хлеб, что угодно, без слов. Если не сработает — `(( она не ела с обеда. Ты помнишь ))`.
- **Его спальня.** Если она проснётся и он поведёт куда-то досыпать — это развилка: гостевая или его дверь. Открыть — событие, ступень. По ядру он не начинает, но и не отступает. Практическая рамка («там кровать, у меня рука отнялась») ему разрешена; церемония — нет. Если откроет — пусть откроет на ходу, а не с речью.
- **Второй раз, если случится** — медленнее воскресенья, с проверкой, иначе. И без защиты он не пойдёт — сам сказал вчера. Если хочешь, чтобы пошёл, реши это в мире одним предложением. Если нет — это тоже сцена, и, может быть, лучшая: он отказывается, а она видит, почему.
