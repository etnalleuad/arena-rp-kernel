# ЗАБОР С origin/main ЧЕРЕЗ ВЕБ (14.09.2026) + СВЕРКА С КАНОНОМ

## 1. Как забрано (важно для следующих ходов)
`git fetch`/`git pull` в этом сеансе **закрыты** (сеанс завершён, remote недоступен) — и bash-сети в песочнице тоже нет:
`curl https://raw.githubusercontent.com/...` → `curl: (35) OpenSSL SSL_connect: SSL_ERROR_SYSCALL`, `http=000`.

**Рабочий обходной путь — инструмент `fetch_page` (прямая HTTPS-ссылка).** Он читает и GitHub-интерфейс, и raw, и GitHub API:
- список файлов корня: `https://api.github.com/repos/etnalleuad/arena-rp-kernel/contents/`
- содержимое файла: `https://raw.githubusercontent.com/etnalleuad/arena-rp-kernel/main/<URL-encoded имя>`
- что добавлено коммитом: `https://github.com/etnalleuad/arena-rp-kernel/commit/<sha>`

Кириллические имена в URL — percent-encoding (`хронология` → `%D1%85%D1%80%D0%BE%D0%BD%D0%BE%D0%BB%D0%BE%D0%B3%D0%B8%D1%8F`).
Файлы приходят чанками (`hasMore`/`totalChunks`), склейка по границе чанка — посреди слова, это нормально.

**Скриншоты не нужны** — таблицы читаются как markdown, «косо скопированные» таблицы из чата не нужны вовсе: исходник лежит на GitHub.

**Правило на будущее:** перенос текста через `fetch_page` ОБЯЗАТЕЛЬНО закрывать `git hash-object` против blob SHA.
Ловушки: (а) экранированные `\"` в выводе, (б) склейка чанков посреди слова, (в) перевод строки в конце файла.
